2. Simpan sebagai: d:\spotify-spy\custom_icon.png
3. Edit script create_icons.py:
   input_image = "d:/spotify-spy/custom_icon.png"
4. Run: python create_icons.py
5. Rebuild: gradlew.bat assembleDebug
