📱 CARA INSTALL KE HP ANDROID:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

CARA 1: Transfer File (PALING MUDAH)
────────────────────────────────────────────────────────────
1. Copy file app-debug.apk ke HP (via USB/Bluetooth/Email)
2. Buka file di File Manager HP
3. Tap file untuk install
4. Izinkan "Install from Unknown Sources" jika diminta
5. Tap "Install"
6. Done! Aplikasi sudah terinstall


CARA 2: Via ADB (jika HP terhubung USB dengan USB Debugging ON)
────────────────────────────────────────────────────────────
1. Hubungkan HP ke PC via USB
2. Aktifkan USB Debugging di HP
3. Buka Command Prompt/PowerShell
4. Ketik: adb install app\build\outputs\apk\debug\app-debug.apk
5. Done!


⚠️  TROUBLESHOOTING:
━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━━

❌ "Gradle Sync Failed"
✅ Solusi:
   - Pastikan internet connected
   - File → Invalidate Caches → Invalidate and Restart
   - Retry sync


❌ "SDK not found"
✅ Solusi:
   - Tools → SDK Manager
   - Install Android SDK 34
   - Sync ulang


❌ "Out of memory"
✅ Solusi:
   - Close aplikasi lain yang tidak perlu
   - Bersihkan space lagi (minimal 1 GB free)


❌ "Build Error: Cannot resolve symbol"
✅ Solusi:
   - File → Sync Project with Gradle Files
   - Build → Clean Project
   - Build → Rebuild Project
