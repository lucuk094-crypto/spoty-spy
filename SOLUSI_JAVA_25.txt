LANGKAH 1: SYNC PROJECT DI ANDROID STUDIO
────────────────────────────────────────────────────────────

Di Android Studio:

1. Klik tombol "Sync Now" yang muncul di banner atas
   (atau)
   File → Sync Project with Gradle Files

2. Tunggu proses sync (2-5 menit):
   • Download Gradle 8.12
   • Download Android Gradle Plugin 8.7.3
   • Download dependencies
   • Configure project

3. Pastikan muncul "Sync successful" di status bar


LANGKAH 2: BUILD APK
────────────────────────────────────────────────────────────

Setelah sync berhasil:

1. Build → Build Bundle(s) / APK(s) → Build APK(s)

2. Tunggu build selesai (1-3 menit)

3. Notifikasi "Build successful" akan muncul

4. Klik "locate" untuk buka folder APK


LANGKAH 3: APK SIAP!
────────────────────────────────────────────────────────────

APK akan tersimpan di:
app\build\outputs\apk\debug\app-debug.apk
