MASALAH: "Gradle Sync Failed"
────────────────────────────────────────────────────────────
SOLUSI:
1. Pastikan internet connected dan stable
2. File → Invalidate Caches → Invalidate and Restart
3. Tunggu Android Studio restart
4. Sync ulang


MASALAH: "Failed to download Gradle 8.12"
────────────────────────────────────────────────────────────
SOLUSI:
1. Check free space: harus ada minimal 500 MB
   (sekarang: 1.1 GB ✅)
2. Check internet connection
3. Retry sync
4. Jika masih gagal:
   • Close Android Studio
   • Hapus folder: C:\Users\vanx3\.gradle\wrapper\dists\gradle-8.12-bin
   • Buka Android Studio lagi
   • Sync ulang


MASALAH: "SDK not found" atau "compileSdk 34 not found"
────────────────────────────────────────────────────────────
SOLUSI:
1. Tools → SDK Manager
2. Tab "SDK Platforms"
3. Centang "Android 14.0 (API 34)"
4. Apply → OK
5. Tunggu download selesai
6. Sync ulang


MASALAH: "Cannot resolve dependencies"
────────────────────────────────────────────────────────────
SOLUSI:
1. Pastikan internet connected
2. Build → Clean Project
3. File → Sync Project with Gradle Files
4. Retry build


MASALAH: "Out of memory"
────────────────────────────────────────────────────────────
SOLUSI:
1. Close aplikasi lain yang tidak perlu
2. Pastikan free space minimal 1 GB
3. Restart Android Studio
4. Retry build


MASALAH: Build error "Duplicate class"
────────────────────────────────────────────────────────────
SOLUSI:
1. Build → Clean Project
2. Build → Rebuild Project
3. Jika masih error, coba:
   • File → Invalidate Caches → Invalidate and Restart
