1. Buka https://vercel.com
2. Login/Sign up
3. Klik "Add New..." → "Project"
4. Import: "lucuk094-crypto/spoty-spy"
5. ⚠️ PENTING: Set "Root Directory" = vercel-deploy
6. Framework Preset: "Other"
7. Build Settings: (kosongkan semua)
8. Klik "Deploy"
9. Tunggu ~30 detik
10. Done! Dapat URL


METODE 2: DEPLOY DARI CLI
────────────────────────────────────────────────────────────

# Install Vercel CLI
npm install -g vercel

# Login
vercel login

# Navigate ke folder
cd d:\spotify-spy\vercel-deploy

# Deploy
vercel --prod

# Jawab pertanyaan:
# - Set up and deploy? Y
# - Project name? spotify-spy
# - Directory? ./

# Done! Dapat URL

3. Pastikan ada:
   ✓ index.html
   ✓ manifest.json
   ✓ sw.js
   ✓ icon-192.png
   ✓ icon-512.png
   ✓ vercel.json

1. Vercel Dashboard → Project → Settings
2. "Clear Cache"
3. Deployments → Redeploy
